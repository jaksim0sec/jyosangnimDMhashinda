# 역사 단톡 플레이어 · StoryChat

역사 기반 창작 패러디 쇼츠를 위한 브라우저 전용 가상 메신저 제작 도구.

## 사용 방법

1. `index.html`을 브라우저에서 열거나 배포된 웹사이트에 접속합니다.
2. `char[]`에서 등장인물을 설정하고 대사를 작성합니다.
3. 이미지를 업로드한 다음 `picture$1;`처럼 번호로 연결합니다.
4. **인물별 프로필 설정**에서 프사를 선택하거나 업로드할 수 있습니다. 선택값은 대본 `char[]`에 반영됩니다.
5. 미리보기로 확인하고 **녹화**로 720×1280 WebM 파일을 만듭니다.

## 대본 규격

```text
title$요동정벌 추진위원회;
clock$1388년 5월 · 위화도;
char[
이성계$1$#6B826F;
우왕$👑$#C8A46B;
]
send$우왕$요동 언제 도착함?$900$450;
typing$이성계$1000$750;
send$이성계$돌아갈 거임$1200$350;
picture$이성계$2$850$500;
file$우왕$명령서.pdf$1.3 MB$900$400;
wait$750;
system$회군 시작$500;
```

`send$인물$대사$입력시간(ms)$대기시간(ms);`

이미지 번호는 업로드 시 자동 부여되고 같은 브라우저의 IndexedDB에 저장됩니다. 다른 기기와 서버로 자동 동기화되지는 않으므로, 이미지 파일과 대본은 별도로 보관하세요.

현재 녹화는 **영상만 포함한 WebM**으로 저장되며, 소리·MP4 내보내기는 지원하지 않습니다. 브라우저가 `MediaRecorder` / `captureStream`을 지원해야 녹화할 수 있습니다.

이 UI는 실제 카카오톡이 아닌 **창작용 가상 메신저**입니다.
